1项目简介

Lc 登录管理工具是一款安卓端的账号登录管理工具，主要用来管理游戏账号的上号、抓号与挂机。 核心能力是伪装卸载 QQ：把手机上的 QQ 临时隐藏起来，让游戏调起本工具完成登录， 全程不删除任何聊天记录与登录状态，随时可以一键恢复。

主要功能

  • 上号 — 选择已保存的账号数据，直接登录游戏
  • 抓号 — 捕获游戏登录过程中产生的账号数据，自动保存归档
  • 挂机 — 保持登录状态，适合长时间在线场景
  • 伪装卸载 QQ — 真卸载但完整保留数据，恢复时后台静默安装
  • 数据管理 — 账号文件按游戏分类存放，可查看、编辑、去重
  • 号况验证 — 批量检查账号是否可用
免费说明：本工具从做出来到现在一直免费，没有广告、没有会员、没有次数限制。 唯一的要求是进粉丝群拿一个使用口令。觉得好用的话，帮忙推荐给需要的人就是最大的支持。

3版本怎么选

两个版本功能一样，区别只在于「怎么把 QQ 藏起来」这一步。

需要提权

免 Root 隐藏 QQ 版本

适合：手机上还装着真 QQ，需要在游戏登录时把 QQ 临时藏起来。

要求：Root 或 Shizuku，二选一，有哪个用哪个。

特点：真卸载、数据完整保留，恢复时后台静默安装。

零配置

卸载 QQ 使用版本

适合：可以把手机上的 QQ 直接卸掉，用本工具顶替 QQ 的位置。

要求：什么都不用装，不用 Root，不用 Shizuku。

注意：安装前要先卸载手机上原有的 QQ（包名冲突）。

卸载前务必：如果你选「卸载 QQ 使用版本」，先把手机里原有 QQ 的聊天记录备份好， 卸载会清除 QQ 本地数据。选「免 Root 隐藏 QQ 版本」则不需要这一步，它不动你的数据。

4Root 激活教程

手机已经 Root（装了 Magisk 或 KernelSU）的话，走这条路最简单，配一次永久有效。

1

确认 Root 环境正常

打开 Magisk 或 KernelSU，确认首页显示已安装且版本正常。如果显示「未安装」，说明 Root 环境本身有问题，先修好再来。

2

给本工具授权 su

打开本工具，点「伪装卸载 QQ」。这时系统会弹出超级用户请求框（Magisk 的授权弹窗），选允许，并勾选「记住选择」，以后就不再问。

如果没弹窗，去 Magisk → 超级用户 → 找到本工具 → 手动开启授权。

3

确认状态行变绿

回到主页，顶部状态行应该显示绿色的「Root 激活」。看到这个就说明配置好了，可以直接用。

Root 方式的特点：隐藏走 pm hide，秒完成；恢复走 pm unhide，也是秒完成。 全程不碰 /data/data/ 下任何文件，聊天记录和登录状态一个字节都不会动。 手机重启也不影响，不用重新配置。
如果提示「pm hide 未生效」：说明你的系统（部分 ColorOS / OriginOS / HyperOS）拦截了这条命令。 本工具不会用「禁用」来蒙混过关 —— 那样伪装不彻底，设置里还能看到 QQ。这种情况建议改用 Shizuku 方式。

5Shizuku 激活教程（免 Root）

手机没有 Root 的话，用 Shizuku 借系统权限，效果和 Root 一样。

1

安装 Shizuku

在应用商店或粉丝群里搜索「Shizuku」下载安装。它是开源工具，专门给这类软件借系统权限用，本身不带任何其他功能。

2

激活 Shizuku

安卓 11 及以上（推荐）：

① 打开系统设置 → 关于手机 → 连续点「版本号」7 次，开启开发者选项

② 开发者选项里找到「无线调试」，打开它

③ 回到 Shizuku，点「通过无线调试启动」→ 按提示配对（输入配对码）

安卓 10 及以下：需要用电脑通过 ADB 命令启动 Shizuku，具体步骤看 Shizuku 首页的说明。

已有 Root 的机器：直接在 Shizuku 里点「通过 Root 启动」，最快。

3

给本工具授权

回到本工具，主页点「去授权」，系统弹窗里选「始终允许」。

4

确认状态行变绿

状态行显示绿色的「Shizuku 激活」就配置好了。如果显示「Shizuku·进程通道」，也是正常的，功能一样能用。

Shizuku 会掉线：手机重启后 Shizuku 会停止运行，需要重新打开它（安卓 11 以上通常打开 Shizuku 就自动恢复了）。 另外不要清理 Shizuku 的后台，也不要在系统设置里限制它的电池，否则会频繁掉线。

6日常使用方法

第一次使用

1

首次打开会要求输入口令。口令在粉丝群公告里，输入正确即可进入。连续输错 3 次会自动退出。

2

首次进入主页会弹一个使用教程，强制阅读 5 秒后可以关闭。以后想再看，点主页最下面的「使用教程」。

3

抓号需要读写存储权限。安卓 11 以上需要「所有文件访问权限」，按系统提示授权即可。不给的话抓不到号。

日常操作流程

步骤做什么
① 选模式主页选「上号」「抓号」或「挂机」。三种模式不能同时用，切换即可。
② 隐藏 QQ点「伪装卸载 QQ」。等提示成功后，QQ 图标会从桌面消失。
③ 登录游戏打开游戏，点游戏里的 QQ 登录按钮，会调起本工具完成登录。
④ 恢复 QQ用完点「取消伪装 QQ」，QQ 会自动装回来，数据完整。

数据保存在哪

抓到的账号数据保存在：

/storage/emulated/0/1LICN/数据号/

按游戏名分文件夹，一个账号一个 txt 文件，编号自动分配。可以直接用文件管理器查看、编辑、备份。

遇到问题怎么反馈

主页 → 工具 → 导出全部日志。会打包成一个压缩包，把它发到粉丝群，能大幅加快定位速度。

日志里不包含你的账号内容（access_token 等敏感信息一个字节都不会打包），只包含运行状态、命令执行记录和错误信息，可以放心发。

8常见问题

伪装卸载后数据会丢吗？

不会。免 Root 方式走的是 pm uninstall -k（保留数据卸载）， /data/data/ 和 /sdcard/Android/data/ 下的数据都完整保留， 连应用 uid 都不变。恢复时重新安装同一个包，数据直接就能读到。

程序里做了五道保险：备份字节数必须一致、卸载前取不到 uid 就中止、只允许 -k 卸载、 卸载后验证数据目录仍在、恢复后比对 uid 与目录属主。任何一步不通过都会中止并提示。

提示「免 Root 装不上」怎么办

v225 已修复这个问题。根因是程序读文件大小时读错了数字（读成了 1 字节）， 导致安装包校验永远失败，只能退回一条被系统 SELinux 拦住的安装路径。

如果更新到 v225 还是装不上，会弹出提示框告诉你安装包路径，你可以用文件管理器手动打开安装。 记得选「覆盖安装 / 更新」，不要选「卸载后重装」。

显示「绑定失败，点重新连接」但功能其实能用

这是 v223 之前的界面显示问题，v225 已修复。后台服务（UserService）绑不上时， 程序会自动改走「进程通道」，功能完全正常，但旧版界面会误报失败。

v225 会正确显示实际走的通道，看到「Shizuku·进程通道」是正常的，不用去点重连，也不用重启 Shizuku。

一直显示「未检测到 Shizuku」

按顺序排查：

① Shizuku 是否正在运行（打开 Shizuku 看首页状态）

② 手机是否重启过（重启后 Shizuku 会停，需要重新激活）

③ 是否清理了 Shizuku 的后台，或限制了它的电池

④ 无线调试是否还开着（安卓 11 以上需要保持开发者选项里的无线调试开启）

提示「Shizuku 权限被系统限制」

说明 Shizuku 已经激活、授权也给了，但系统把权限卡住了。按两步处理：

① 系统设置 → 应用管理 → Shizuku → 电池 → 选「无限制 / 允许后台活动」

② 同样把本工具也设为「无限制」，然后重启一次 Shizuku

做完回来点「重新连接」即可。

伪装卸载时提示「pm hide 未生效」

说明你的系统拦截了 pm hide 命令，部分 ColorOS、OriginOS、HyperOS 会有这个限制。

本工具不会用「禁用应用」来代替 —— 那样伪装不彻底，设置的应用管理里还能看到 QQ。 建议改用 Shizuku 方式，或者用「卸载 QQ 使用版本」。

取不到 QQ 号 / 无法卸载

v225 已修复。原来只走一条命令取应用 uid，取不到就卡住。现在改成四条路径兜底： pm list packages -U → stat 数据目录 → dumpsys package → ls -ld 解析。

如果四条都失败，会明确报错而不是卡住。

为什么安装包这么小（400 多 KB）

因为代码经过压缩优化，没有多余依赖。包体主要构成：

· 代码约 180 KB　· 赞赏二维码约 122 KB（高清图，安卓对图片资源默认不压缩存储）　· 应用图标约 43 KB

没加任何后台常驻服务，也不含广告 SDK。

能不能同时装两个版本

两个版本包名不同（一个是 com.tencent.tim，一个是 com.tencent.mobileqq）， 理论上可以共存，但「卸载 QQ 使用版本」会顶替真 QQ 的包名，装它之前必须先卸掉手机上的真 QQ。

同一台手机建议只装一个版本，按自己的情况选。

9v225 更新日志

重点修复

  • 免 Root 装不上 — 程序读错了安装包大小（读成了 1 字节），校验永远不通过，只能退回一条被系统拦住的安装路。之前反复反馈「免 Root 装不上」基本都是它。这个 bug 存在很久了。
  • 隐藏失败 — 判断「是否隐藏成功」的逻辑有漏洞，通道没通时会误报「伪装卸载成功」。现在按真实状态复核，失败就如实说失败，不会再骗你。
  • 取不到 QQ 号 — 取 uid 从一条命令改成四条路径兜底，取不到才报错。

体验优化

  • 速度 — 伪装卸载和一键恢复从 3 秒多降到几百毫秒。以前每条命令都要先干等 3 秒才发现走不通再换路。
  • 界面误导 — 后台服务绑不上时界面会显示「绑定失败，点重新连接」，但功能其实正常。现在会显示真实通道。
  • 防连点 — 伪装卸载 / 一键恢复 3 秒内只准点一次，执行期间按钮变灰。以前连点会同时跑好几个线程抢同一份备份，既慢又有写坏备份的风险。

新增功能

  • 使用教程 — 主页最下面加了入口，Root 和 Shizuku 两种激活方式分开写，第一次用照着做就行。首次进入会强制看完 5 秒，之后随时可以点开复习。
